Statuses: `PROVEN`, `TARGET`, `BLOCKED`, `REJECTED`. No "basically proven," no "should work."

Code existing for a claim does not promote it. Only committed evidence (a resolved fixture, a signed transaction, a reproducible script output) promotes it.
