09FAQ

Questions, answered plainly.

What is Marked?+
Marked is a governance fulfillment layer that binds an approved governance action to deterministic execution and independent outcome verification.
Isn't this just Cactus's Execute button?+
No. Cactus provides the governance operating surface and already supports execution. Marked focuses on the operational last mile: freezing the authorization, waiting for eligibility, bounded KeeperHub execution, and independently verifying the intended outcome.
Does Marked decide what a DAO should do?+
No. Governance creates authority. Marked may fulfill existing governance authority; it cannot create it.
What does KeeperHub do?+
KeeperHub provides the managed execution surface used for the bounded onchain lifecycle call, including simulation and execution infrastructure.
Why isn't a successful transaction enough?+
Because transaction success proves execution did not revert. It does not necessarily prove the intended economic/protocol outcome occurred. Marked verifies supported postconditions independently.
Can an AI agent change the transaction?+
No. The agent may prepare and explain. The frozen commitment constrains runtime execution.
What happens if the proposal changes?+
Marked refuses execution when the current Governor authorization no longer matches the frozen authorization.
What happens if the timelock hasn't matured?+
Marked waits. It does not submit early.
Does Marked work with every Governor and protocol?+
No. Current support is deliberately bounded (Governor Bravo, ERC20 transfers). Unsupported authorization families or economic effects fail closed rather than being silently approximated.
Is this running on mainnet?+
The current execution proof is controlled Sepolia. Live Cactus governance resolution has separately been proven against real mainnet governance objects. These are two separate proofs, never presented as one.
What does MARKED ✓ mean?+
It means the frozen governance authorization, actual execution, final Governor state, and independently observed supported postcondition all reconciled.
Can I verify a receipt myself?+
Yes — see the verification docs and the evidence page.
